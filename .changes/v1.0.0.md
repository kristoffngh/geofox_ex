## v1.0.0 - 2026-10-14
### Added
* Client.new/1 accepts :req_options to pass extra options to Req (e.g. a Req.Test plug)
### Changed
* Require Elixir ~> 1.15 (needed by req 0.7.5)
### Fixed
* The :retry option now works (true retries transient failures, up to :max_retries)
* User-Agent now reports the geofox_ex version instead of `dev`
* HMAC signature is now computed over the exact bytes sent in the request body
### Security
* Upgraded `req` dependency (0.4.0 -> 0.7.5)
* Removed unused `timex` dependency
* Removed unused `bypass` dependency
